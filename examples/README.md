# Examples

Examples show the project value without requiring readers to learn the full method first.

Each example should answer four questions:

- What was the messy input?
- How was it classified?
- What action or audit artifact did it create?
- How can a future task reuse it?

## Available Examples

| Example | Shows |
|---|---|
| [ai-consulting-replacement](ai-consulting-replacement/) | A hot AI claim becoming a weak-signal sample, action plan, audit report, and reuse decision. |

## Expected Chain

```text
raw input
  -> goal check
  -> classified sample
  -> action plan
  -> audit report
  -> reuse decision
```

This is the smallest proof that Mercury Lab is not just cleaning notes. It keeps the judgment state and future reuse path visible.
