# Meshy Game Studio《代号：黑箱》产品发布与AI原生游戏战略分析

（原始材料来源：Meshy AI 官方公众号，游戏《代号：黑箱》发布公告与创始人心得）

## 核心内容摘要

### 创始人背景
- 清华姚班毕业，MIT计算机图形学博士（论文项目Taichi编程语言获SIGGRAPH最佳博士论文提名）
- 创立Meshy AI（3D AI全球市场份额第一，ARR近4000万美元，红杉/源码/GGV投资）
- 2014年在清华读书时做数字消除游戏《Not a Number》，一周吸引近20000人玩
- 2014 NOI出题《消除游戏》
- 内心深处是gamer，创业成功后背负做游戏的初心

### 现有AI+游戏方案总结（及其局限）
1. 世界模型（Genie 3类）：风景模拟器，非游戏本质
2. AI对话（Character.ai类）：巨大流量但非游戏体验
3. AI生成素材换皮：ROI算不清楚，留存率不变甚至降低
4. AI一键生成游戏（Rosebud AI）：质量普遍不高
5. AI小镇（斯坦福小镇）：玩家参与度低
6. AI生成剧情：小成本有成功案例

### 第一性原理分析
- 游戏成功的关键只有一点：**好玩**
- 已有AI+游戏没有让游戏变得更好玩
- 顶尖游戏（时空幻境/BotW）的共同点：刨去画面，游戏机制是核心
- 结论：AI原生游戏必须做"AI生成游戏机制"

### 启发来源
1. 暗黑破坏神2：固定技能树限制了build自由度
2. Noita（法术编程模拟器）：自由度极高但门槛过高（MIT PhD需10小时入门）
3. 吸血鬼幸存者：游戏性极强但武器合成不够自由
4. 塞尔达传说：王国之泪"余料建造"：直观低门槛但自由度有限

### 核心挑战：三角不可能
- **自由**（任何操作可能）× **直观**（结果可预期）× **低门槛**（人人可上手）
- 现有神作最多做到其中两点

### 解决方案：AI游戏机制生成大模型
- 基于Meshy AI的多模态大模型训练能力
- 建立游戏机制数据集，训练模型输出无穷无尽机制
- 实现"言出法随"式合成
- 案例：召唤爆破无人机、激光枪、追踪激光无人机、移动黑洞等

### 产品《代号：黑箱》
- 类型：类暗黑/刷子游戏+Loot刷宝
- 核心循环：打怪→采购→AI合成武器→打更多怪
- 合成示例：C4+霰弹枪=散射C4枪；+回旋镖=回旋护体弹
- 定位：首款"真正好玩的AI原生游戏"
- 状态：早期开发中，下周GDC Meshy Labs展台（941）开放试玩
- 预计几个月后Steam上线，支持中文
- Steam搜索：Black Box: Infinite Arsenal

### 团队信息
- 核心成员来自腾讯、网易、FunPlus
- 创始人MIT博士，曾做《Not a Number》（20000用户）、2048启发产品
- 资金：已实现近4000万美元ARR，红杉/源码/GGV支持
- 招聘方向：平衡性/心流、特效/粒子、美术/打击感、AI生成范围扩大、多模态AI引擎

### 核心理念
- "科学、艺术与乐趣"：技术决定能做什么；艺术品味决定不做什么；乐趣创意给做下去的动力
- AI解决收入问题后，人类最底层需求：获得快乐体验+活出无限意义
- AI原生游戏将成为未来最受欢迎的快乐体验生成工具
