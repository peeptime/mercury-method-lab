## Original Submission

脚本 → RPA → 语音助手 → 定制型 Agent → OpenClaw 类个人 Agent 网关。但严格说，OpenClaw 不是单纯比定制型 Agent 更高级，而是位置不同。定制型 Agent 更像一个专门工人。OpenClaw 更像给多个专门工人接电话、派活、拿工具、回消息的调度台。更统一表达：脚本解决机器按步骤做事。RPA 解决机器替人点软件。语音助手解决人用自然语言触发功能。定制型 Agent 解决AI在某个任务域内执行。OpenClaw 类项目解决AI如何接入个人工具流并成为调度入口。最关键的代际差异：对比旧自动化 OpenClaw 类，输入命令/触发器/流程 vs 意图/上下文；执行固定步骤 vs 临场规划；工具单点或固定链路 vs 多工具网关；入口某个软件内 vs 聊天通道、本地系统、工具层；可迁移性流程变了就要重配 vs 理论上可根据上下文调整；风险主要是流程错误 vs 权限、误操作、越权执行、安全边界。最终一句话：OpenClaw 类项目不是更聪明的 RPA，而是脚本、RPA、语音助手之后，自动化入口从流程触发转向意图调度的早期形态。
