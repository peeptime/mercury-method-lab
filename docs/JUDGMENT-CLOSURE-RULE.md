# Judgment Closure Rule

## 目的

Mercury Lab 不鼓励无限分析。

每个完整 PSP 判断都必须给出关闭条件，让用户知道什么时候停止、什么时候复盘、什么信号会推翻当前判断，以及这条判断是否值得进入记忆。

## 必填尾部

完整分析必须包含：

```text
【停止条件】满足什么条件后停止继续分析？
【推翻条件】什么信号出现说明当前判断错了？
【复盘时间】什么时候回来检查？
【记忆建议】M0-M4，为什么？
```

## 外部审计新增检查

审计报告除结构完整性外，还必须检查：

- 证据是否独立。
- 是否存在循环论证。
- 哪些是输入事实，哪些是模型推断。
- 是否存在反例或缺失反例搜索。
- 停止条件是否可执行。
- 记忆等级是否过高。

## 记忆等级

| 等级 | 含义 |
|------|------|
| `M0` | 不建议记忆 |
| `M1` | 可短期保留 |
| `M2` | 可作为项目上下文 |
| `M3` | 可进入长期方法论 |
| `M4` | 重大修正，需高优先级保存 |

默认等级应偏保守。未经复盘或外部证据支持的结论，通常不应高于 `M2`。
