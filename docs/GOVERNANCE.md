# Mercury Lab 目标定义

> 版本：0.1.0
> 日期：2026-05-04
> 状态：核心目标已确认，架构对齐中

---

## 核心目标

**把碎片化洞察转化为项目先行的可验证样本库。**

Mercury Lab 做成以后，应该发生的事情是：

> 你不再把洞察停留在聊天里，而是每次都能把它分流成：
> **废料 / 素材 / 案例 / 模板 / 决策 / 行动计划 / Skill**
>
> 这些碎片不再悬空，而是绑定真实项目，形成可复盘链路。

---

## 意义

| 发生的事 | 意义 |
|---------|------|
| 一个想法进来，不直接进长期记忆 | 防止"干净垃圾"堆积 |
| 每个想法被判级：素材/观察/假设/案例/模板/决策/Skill | 碎片有工程状态 |
| 没过四关的概念不抬成方法论 | 防止概念自嗨 |
| 真正有用的碎片绑定项目 | 知识不再悬空 |
| 每个项目逐渐积累 raw/cleaned/audit/decision/action_plan | 形成可复盘链路 |
| OpenClaw / Codex 后续能直接读取这些样本和约束 | 变成个人 agent 训练地基 |
| 回看：哪些想法被淘汰、哪些变成模板、哪些影响决策 | 形成认知资产审计轨迹 |

---

## 核心数据流

```
碎片输入
  → 原文保留（raw）
  → 去噪清洗（cleaned）
  → 类型判级
  → 绑定项目
  → 四关检验
  → 生成 artifact
  → 审计/决策/行动
  → 进入样本库
  → 后续复用或淘汰
```

---

## 判级类型

每个碎片在经过 pipeline 后，被判级为以下类型：

| 类型 | 含义 | 样本库位置 |
|------|------|-----------|
| **废料** | 不可用，淘汰 | 不入库 |
| **素材** | 有价值但未整理 | 04_memory_candidates |
| **观察** | 事实性记录，待验证 | 02_cleaned |
| **假设** | 推断性结论，待案例检验 | 03_uncertain |
| **案例** | 经四关验证的真实场景 | 04_memory_candidates |
| **模板** | 可复用的标准化流程或格式 | 09_templates |
| **决策** | 已采纳的判断，含反馈结果 | 05_decision_logs |
| **行动计划** | 含验收条件和闭环跟踪 | 06_action_plans |
| **Skill** | 已固化的可执行工作流 | 08_skills |

## 当前最大的空白

**样本库有内容，但没有索引和检索机制。**

现在的状态：
- artifact 分布在 11 个目录里
- 没有系统知道哪些碎片"后来怎么样了"
- 下一个相似任务进来，Agent 不知道参考哪个样本
- 没有淘汰机制，老旧 artifact 永远存在

**缺失的不是更多 artifact，是"后来的 artifact 怎么找到前面的样本"和"样本用完怎么打标签"。**

---

## 下一步方向

按优先级：

1. **样本库索引系统**（最关键）
   - 给每个 artifact 打标签：关联项目 / 来源类型 / 验证状态
   - 让后来者能找到相似案例

2. **复用追踪机制**
   - 每次新任务进来，检查相似样本
   - 样本被引用时记录"被复用次数"
   - 长期无引用 → 降级或淘汰

3. **判级结果写入 artifact metadata**
   - 每个 artifact 的元数据里明确记录判级类型
   - 方便索引和检索

4. **反馈注入口**
   - decision_log / action_plan 执行结果必须回填
   - feedback 未回来的 artifact 不进 M3/M4
