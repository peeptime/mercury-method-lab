# Mercury Lab 目标定义

> 版本：0.2.1
> 日期：2026-05-04
> 定位：面向高频 AI 对话者的「洞察样本沉淀系统」

---

## 核心定位

Mercury Lab 不是普通知识库，也不是通用 AI 审计平台。

它解决的问题是：高价值想法经常出现在聊天、碎片、临时判断和项目讨论中，但如果没有目标验证、类型判级、案例绑定、审计记录和复用出口，它们很快会变成干净但无用的知识碎片。

**Mercury Lab 的目标，是把这些碎片加工成可追踪、可判断、可复用的项目样本。**

---

## 核心目标

**把碎片化洞察转化为项目先行的可验证样本库。**

Mercury Lab 做成以后，应该发生的事情是：

> 你不再把洞察停留在聊天里，而是每次都能把它分流成：
> **废料 / 素材 / 案例 / 模板 / 决策 / 行动计划 / Skill**
>
> 这些碎片不再悬空，而是绑定真实项目，形成可复盘链路。

---

## 意义

| 发生的事 | 意义 |
|---------|------|
| 一个想法进来，不直接进长期记忆 | 防止"干净垃圾"堆积 |
| 每个想法被判级：素材/观察/假设/案例/模板/决策/Skill | 碎片有工程状态 |
| 没过四关的概念不抬成方法论 | 防止概念自嗨 |
| 真正有用的碎片绑定项目 | 知识不再悬空 |
| 每个项目逐渐积累 raw/cleaned/audit/decision/action_plan | 形成可复盘链路 |
| OpenClaw / Codex 后续能直接读取这些样本和约束 | 变成个人 agent 训练地基 |
| 回看：哪些想法被淘汰、哪些变成模板、哪些影响决策 | 形成认知资产审计轨迹 |

---

## 核心数据流

```
碎片输入
  → 原文保留（raw）
  → 去噪清洗（cleaned）
  → 类型判级
  → 绑定项目
  → 四关检验
  → 生成 artifact
  → 审计/决策/行动
  → 进入样本库
  → 后续复用或淘汰
```

---

## 判级类型

每个碎片在经过 pipeline 后，被判级为以下类型：

| 类型 | 含义 | 样本库位置 |
|------|------|-----------|
| **废料** | 不可用，淘汰 | 不入库 |
| **素材** | 有价值但未整理 | 04_memory_candidates |
| **观察** | 事实性记录，待验证 | 02_cleaned |
| **假设** | 推断性结论，待案例检验 | 03_uncertain |
| **案例** | 经四关验证的真实场景 | 04_memory_candidates |
| **模板** | 可复用的标准化流程或格式 | 09_templates |
| **决策** | 已采纳的判断，含反馈结果 | 05_decision_logs |
| **行动计划** | 含验收条件和闭环跟踪 | 06_action_plans |
| **Skill** | 已固化的可执行工作流 | 08_skills |

## 当前最大的空白

**样本库已有初版索引，但复用和反馈还没有形成闭环。**

现在的状态：
- `npm run index` 会生成 `11_indexes/source-index.json` 和 `11_indexes/sample-index.json`
- `sample-index.json` 已能暴露判级类型、项目绑定、复用计数和反馈状态
- 旧 artifact 大多没有 `sample_type`、`project_id`、`reuse_count`、`feedback_status` 元数据
- 下一个相似任务进来，Agent 仍缺少相似样本召回逻辑
- 没有淘汰机制，老旧 artifact 仍然会永久存在

**当前修正让缺口可见；下一步是让缺口可操作。**

---

## 下一步方向

按优先级：

1. **样本库索引系统二期**
   - 将 `sample-index.json` 接入 Agent 检索入口
   - 给每个 artifact 回填：关联项目 / 来源类型 / 验证状态

2. **复用追踪机制**
   - 每次新任务进来，检查相似样本
   - 样本被引用时记录"被复用次数"
   - 长期无引用 → 降级或淘汰

3. **判级结果写入 artifact metadata**
   - 每个 artifact 的元数据里明确记录判级类型
   - 方便索引和检索

4. **反馈注入口**
   - decision_log / action_plan 执行结果必须回填
   - feedback 未回来的 artifact 不进 M3/M4
