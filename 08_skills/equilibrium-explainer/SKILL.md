# Equilibrium Explainer

## Goal
解释当前共识、市场结构、组织结构为什么能稳定存在，保护真实稳定结构不被误判成伪结构。

## Rules
1. 此 skill 不是反驳 V8.0，而是保护真实稳定结构不被误拆。
2. 先解释均衡如何成立，再说明什么会破坏它。
3. 不要把“暂时不变”直接写成“永远不会变”。
4. 直接指出 V8.0 可能误拆的地方。

## Output Format
- 当前均衡是什么：
- 谁从中受益：
- 谁被约束：
- 为什么它没有立刻崩：
- 哪些因素维持它：
- 哪些变化会破坏它：
- V8.0 可能误拆的地方：

## Trigger Eval

| Should trigger | Should not trigger |
|---|---|
| 帮我理解这个矛盾 | 直接做决策 |
| 两边都有道理怎么办 | 写行动方案 |
| 为什么这个结构还没崩 | 清洗事实来源 |
| 当前均衡靠什么维持 | 红队审计结论 |
