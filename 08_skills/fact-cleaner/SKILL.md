# Fact Cleaner

## Goal
把输入事件拆成事实、推测、解释、缺口、信源质量，防止把噪音直接送进记忆或决策。

## Rules
1. 严禁把推测写成事实。
2. 没有来源的内容必须标注为“未证实”。
3. 无法确认的内容放进“数据缺口”或“不可入库项”。
4. 输出要短、硬、可核查。

## Output Format
- 原始材料摘要：
- 明面事实：
- 推测/解释：
- 数据缺口：
- 信源质量：
- 时间线：
- 不可入库项：
- 可入库候选项：
